# Roadmap de Vectopen

Documentos de planificación a medio y largo plazo. El estado de cada release y
las tareas del próximo milestone viven en el repositorio principal:

- [`ROADMAP.md`](../../ROADMAP.md) — estado por versiones: released, next, in progress y planned.
- [`PENDIENTE.md`](../../PENDIENTE.md) — verificaciones y tareas abiertas a corto plazo.
- [Milestone `0.2.1-alpha`](https://github.com/malabo1990/-Vectopen/milestone/1) — issues del próximo release.
- [`docs/archive/`](../archive/) — documentos históricos (no vigentes).

## Cómo añadir una propuesta

1. Crear el `.md` en esta carpeta con la plantilla: objetivo, arquitectura,
   modelo de datos, fases, riesgos y criterios de validación.
2. Añadirlo a la tabla de arriba.
3. Si entra en el alcance de un release, abrir issues y enlazarlas desde el
   milestone correspondiente.
4. Mantener el texto honesto: marcar lo que es propuesta frente a lo ya
   implementado.
